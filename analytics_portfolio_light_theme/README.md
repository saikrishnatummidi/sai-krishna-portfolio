# Professional Analytics Portfolio

Light-theme portfolio starter for a Power BI Developer / Data Analyst.

## Open in VS Code

1. Extract the ZIP.
2. Open the extracted `analytics_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
4. Replace the placeholder text, links and images.

## Important files

- `index.html` — all portfolio content and links.
- `style.css` — theme, layout, responsive design and hover effects.
- `script.js` — mobile navigation and small scroll animations.
- `assets/images/profile.jpg` — replace with your round profile photo.
- `assets/images/projects/` — put dashboard screenshots here.
- `assets/images/certifications/` — put certificate images here.
- `assets/resume.pdf` — replace with your resume.

## What to replace first

Search for:
- `Your Name`
- `Your Company Name`
- `yourusername`
- `your.email@example.com`
- `#`
- `Your Degree / Course`

Then replace the sample project and certification information with your actual details.

## Recommended image sizes

- Profile: square image, ideally 800 x 800 or larger.
- Project thumbnails: 1600 x 900 (16:9).
- Certification images: around 1600 x 1100 or similar.

## Publishing

For this static HTML/CSS/JS site, Vercel is a very good choice. You can also publish through GitHub Pages. After you finish editing, the next step is to connect your GitHub repository to Vercel and deploy it.
